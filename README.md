# - clientDemo — iOS 消息中心 Demo（含数据分析与增长策略）
本项目是一个使用 SwiftUI + SQLite 构建的高质量 iOS 消息中心 Demo。
功能覆盖消息展示、备注编辑、消息置顶、弱网体验、实时消息模拟、数据埋点、CTR 计算与可视化数据看板。

🧩 项目简介

这是一个模拟真实 抖音消息 系统的 SwiftUI Demo，包含：
	•	消息列表展示
	
    •	本地模拟数据源（JSON）
	
	•	分页加载
	•	置顶功能
  •	支持 3 种消息体裁：纯文本（系统消息）携带图片（好友发图）携带按钮的运营类消息（如“领取奖励”）
  •	实现消息时间文案规则
  •	消息搜索
  •	自定义专场
  •	SQLite Migration
	•	备注编辑（卡片动效）
	•	弱网与错误态体验（Skeleton、重试）
	•	本地 SQLite 状态持久化
	•	Mock 实时消息推送（Timer）
	•	埋点系统（CTR、趋势、消息打开率）
	•	可视化数据看板（Charts）
